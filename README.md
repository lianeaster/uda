# УАД — Українська Академія Дистиляції

Публічний сайт Академії + Навчальна платформа з розмежуванням прав доступу
(супер-адмін, менеджер, викладач, студент).

**Версія 0.2**

## Структура проєкту

- `core/` — публічний сайт: головна, курси, лектори, заявка на консультацію
  (`/`, `/courses/`, `/lecturers/`)
- `accounts/` — кастомна модель користувача з ролями, вхід/вихід, керування
  користувачами з фільтром і сортуванням (`/login/`, `/users/`)
- `dashboard/` — кабінет після входу, контент залежить від ролі (`/dashboard/`)
- `schedule/` — місячний планер-розклад, курси та предмети (`/schedule/`)

## Ролі та права

| Роль | Керування користувачами | Розклад |
|---|---|---|
| Супер-адмін | усі ролі, включно з призначенням супер-адміна | будь-які зміни |
| Менеджер | лише викладач/студент | бронювання зі сторони Академії |
| Викладач | — | свої записи (курс + предмет + викладач) |
| Студент | — | перегляд розкладу обраного викладача |

### Кольори в розкладі

- **Синій** — заброньовано курс, без предмету й викладача
- **Зелений** — визначено курс, предмет і викладача
- **Помаранчевий** — час, де синій і зелений перетинаються

Викладач може редагувати будь-який запис, закріплений за ним, незалежно від
того, хто його створив. Синє бронювання Академії та записи інших викладачів
редагувати не можна.

## Дизайн

Візуальна система перенесена з макета Claude Design: палітра пергамент/мідь,
шрифти Lora (заголовки) + PT Sans (текст), пігулкові контроли, м'які великі
заокруглення, поява блоків при скролі.

## Запуск локально

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

python manage.py migrate
python manage.py createsuperuser   # створити першого супер-адміна
python manage.py runserver
```

Сайт: http://127.0.0.1:8000/ — вхід на платформу: http://127.0.0.1:8000/login/

### Змінні оточення

| Змінна | За замовчуванням | Призначення |
|---|---|---|
| `DJANGO_SECRET_KEY` | ключ для розробки | **обов'язково задати перед деплоєм** |
| `DJANGO_DEBUG` | `1` | `0` вимикає режим налагодження |
| `DJANGO_ALLOWED_HOSTS` | `localhost,127.0.0.1,testserver` | список доменів через кому |

## Наступні етапи

- Прив'язка розкладу до груп студентів
- Спільний календар кількох викладачів на одному екрані
- Профілі студентів/викладачів, матеріали курсів
- Реальні фото лекторів і відео-відгуки замість ілюстрацій-заглушок
