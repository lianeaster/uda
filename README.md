# УАД — Українська Академія Дистиляції

Публічний сайт Академії + Навчальна платформа з розмежуванням прав доступу
(супер-адмін, менеджер, викладач, студент).

**Версія 0.2**

## Структура проєкту

- `core/` — публічний сайт: головна, курси, лектори, заявка на консультацію
  (`/`, `/courses/`, `/lecturers/`)
- `accounts/` — кастомна модель користувача з ролями, вхід/вихід, керування
  користувачами з фільтром і сортуванням (`/login/`, `/users/`)
- `dashboard/` — кабінет після входу, контент залежить від ролі (`/dashboard/`)
- `schedule/` — місячний планер-розклад, курси та предмети (`/schedule/`)

## Ролі та права

| Роль | Керування користувачами | Розклад |
|---|---|---|
| Супер-адмін | усі ролі, включно з призначенням супер-адміна | будь-які зміни |
| Менеджер | лише викладач/студент | бронювання зі сторони Академії |
| Викладач | — | свої записи (курс + предмет + викладач) |
| Студент | — | перегляд розкладу обраного викладача |

### Кольори в розкладі

- **Синій** — заброньовано курс, без предмету й викладача
- **Зелений** — визначено курс, предмет і викладача
- **Помаранчевий** — час, де синій і зелений перетинаються

Викладач може редагувати будь-який запис, закріплений за ним, незалежно від
того, хто його створив. Синє бронювання Академії та записи інших викладачів
редагувати не можна.

## Дизайн

Пігулкові контроли, м'які великі заокруглення, поява блоків при скролі.

### Кольори

Гайдлайн Академії дає дві фірмові фарби, і вся гама виведена з них —
жодного стороннього кольору:

| Токен | Значення | Роль |
|---|---|---|
| `--ink` | `#231f20` | фірмове чорнило, увесь текст |
| `--copper` | `#97694b` | фірмова мідь, кнопки й акценти |
| `--accent-100…400` | `#e8d8c4` → `#b7957b` | мідь, домішана в пергамент |
| `--accent-600…900` | `#805a42` → `#3a2e29` | мідь у бік чорнила, темні панелі |
| `--cream` / `--paper` | `#f5ead8` / `#ebddc5` | підкладка |

Підкладку навмисно тримаємо теплішою за мідь (тон 37-40° проти 24°): чисті
тінти `#97694b` на білому йдуть у рожеве, тому мідь домішується вже в
пергамент, а не в білий.

Бренд не має другої фарби, тож другий тип тегу (`.tag-outline`) відрізняється
не кольором, а формою — контуром замість заливки.

Виняток — кольори статусів у розкладі (синій/зелений/помаранчевий). Вони
несуть зміст, а не стиль, тому лишаються сигнальними.

### Типографіка

Lora (заголовки) + PT Sans (текст). Гайдлайн називає Helvetica Neue Bold —
це шрифт логотипа; на сайті лишили Lora.

Один масштаб на весь сайт, чотири щаблі, жодних довільних розмірів у
компонентах:

```css
--h1: clamp(38px, 4.8vw, 58px);
--h2: clamp(28px, 3.1vw, 40px);
--h3: 21px;
--h4: 17px;
```

Компоненти задають заголовкам лише відступи й колір. Якщо десь потрібен
інший розмір — береться сусідній щабель (`.form-page h1` → `var(--h2)`),
а не нове число.

### Фон

Чотири шари на `body`:

1. `static/img/brand/pattern.svg` — безшовна плитка 460×460 з тонких кілець і
   мідних крапель (відлуння кола логотипа та бульбашок у колбі);
2. дрібне зерно паперу — inline SVG `feTurbulence`;
3. три м'які світлові плями (шавлія, мідь, тепла) на `background-attachment: fixed`,
   тож світло стоїть на місці, а сторінка їде під ним.

На дотикових екранах плями переводяться в `scroll` — `fixed` капризний
на iOS Safari.

### Медіа з основного сайту

Фото, логотипи та відео перенесені з distillingacademy.com.ua і лежать
локально в `static/img/`:

| Тека | Що там |
|---|---|
| `brand/` | логотип Академії, фавікони, apple-touch-icon, плитка фону |
| `platform/` | знак і фавікони Навчальної платформи |
| `lecturers/` | 19 портретів лекторів, 480×480, у білому колі r=41.7% |
| `courses/` | 9 обкладинок курсів |
| `partners/` | 12 логотипів партнерів (PNG з прозорістю) |
| `articles/` | ілюстрації послуг і блогу |
| `photo/` | фотографії Академії (герой, дегустація, виробництво, бочки) |
| `video/` | постери YouTube-відео |

Текстовий контент до них — у `core/content.py`: шаблони лише розкладають
дані по сітці.

Відео не вантажать плеєр одразу: до кліку показано локальний постер, після
кліку `static/js/video.js` підставляє iframe youtube-nocookie.

### Два знаки

Публічний сайт і Навчальна платформа мають різні знаки. У платформи — бронзова
крапля над розгорнутою книгою (з макета), у тих самих двох фірмових фарбах.

| Файл | Де вживається |
|---|---|
| `platform/badge.svg` | повний знак із кільцевим написом — сторінка входу |
| `platform/mark.svg` | знак без напису — шапка платформи (нижче 96 px напис знімається) |
| `platform/mark-light.svg` | біла версія — кнопка «Навчальна платформа» на мідному тлі |
| `platform/tile.svg` + PNG | плитковий знак — фавікони й apple-touch-icon |

Розділення живе в шаблонах: `templates/base.html` має блоки `favicon` і
`brand` зі знаком Академії за замовчуванням, а `templates/platform_base.html`
їх перекриває. Шаблони `accounts/`, `dashboard/` і `schedule/` успадковують
саме його, `core/` — базовий.

### Піктограми

`templates/includes/icon-sprite.html` — SVG-спрайт у стилі логотипа: тонкий
вугільний контур плюс мідний акцент (`#96694c`, колір узятий із логотипа).
Спрайт вбудований у сторінку, тож `<use>` працює скрізь:

```html
<svg class="ic" aria-hidden="true"><use href="#ic-flask"></use></svg>
```

Контур успадковує `currentColor`, мідний акцент — змінна `--ic-accent`
(на темних панелях її освітлено). Кругла плашка `.icon-badge` повторює
кільце логотипа.

Набір: `ic-flask`, `ic-still`, `ic-factory`, `ic-cap`, `ic-drop`, `ic-grain`,
`ic-cask`, `ic-botanical`, `ic-nose`, `ic-ferment`, `ic-lab`, `ic-screen`,
`ic-calendar`, `ic-clock`, `ic-euro`, `ic-people`, `ic-play`, `ic-diploma`.

## Запуск локально

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

python manage.py migrate
python manage.py createsuperuser   # створити першого супер-адміна
python manage.py runserver
```

Сайт: http://127.0.0.1:8000/ — вхід на платформу: http://127.0.0.1:8000/login/

### Змінні оточення

| Змінна | За замовчуванням | Призначення |
|---|---|---|
| `DJANGO_SECRET_KEY` | ключ для розробки | **обов'язково задати перед деплоєм** |
| `DJANGO_DEBUG` | `1` | `0` вимикає режим налагодження |
| `DJANGO_ALLOWED_HOSTS` | `localhost,127.0.0.1,testserver` | список доменів через кому |

## Наступні етапи

- Прив'язка розкладу до груп студентів
- Спільний календар кількох викладачів на одному екрані
- Профілі студентів/викладачів, матеріали курсів
- Реальні фото лекторів і відео-відгуки замість ілюстрацій-заглушок
